# Workshop sample drawings

Original examples created for the DXF Sketcher showcase, 4 October 2026.

| File | Contents |
| --- | --- |
| [01-control-panel.dxf](01-control-panel.dxf) | 180 × 100 mm panel with a display opening, three control openings, mounting holes, slots and vector labels. |
| [02-ventilation-panel.dxf](02-ventilation-panel.dxf) | Matching 180 × 100 mm rear panel with rounded ventilation slots. |
| [03-enclosure-layout.dxf](03-enclosure-layout.dxf) | Front, rear and two 180 × 50 mm side panels in one drawing. |

Units: **millimetres**. Entities: LINE, ARC and CIRCLE. Labels are drawn as lines, so they do not require fonts. These are illustrative drawing examples, not a tested enclosure or production toolpaths. Check fit, material thickness and cutting allowances before fabrication.
