# Reporting a security concern

For a suspected security issue in DXF Sketcher, email **abysstailcrafts@gmail.com** with the subject **DXF Sketcher security report**. This is the project's published maintainer contact.

Include the application version, operating system, affected workflow, impact and minimal reproduction steps. Use a harmless sample; do not send credentials, private drawings or unrelated personal files. Please report sensitive details privately before publishing them.

Ordinary rendering bugs and feature requests belong in [GitHub Issues](https://github.com/EriArk/-DXF-Sketcher/issues).

Reports against the latest published release are most useful. Historical versions remain available for reference; there is no guaranteed response time or maintenance window for older releases. Open security-related work is tracked honestly and should not be interpreted as already fixed.
