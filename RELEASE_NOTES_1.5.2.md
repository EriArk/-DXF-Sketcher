# DXF Sketcher 1.5.2

DXF Sketcher 1.5.2 is a polish and release-quality update.

## Highlights

- Toolbar popovers are cleaner and more consistent across selection, grid, symmetry, gears, cup template, and edge tools
- Edge Tool advanced settings are easier to scan thanks to shorter joint labels and tidier parameter rows
- Several remaining product texts were cleaned up so the app feels less like a fork and more like a cohesive DXF Sketcher release
- AppImage releases now include embedded update metadata and the matching `.zsync` companion for Gear Lever style update flows

## Included Artifacts

- Debian package: `dxfsketcher_1.5.2_*.deb`
- RPM package: `dxfsketcher-1.5.2-1.*.rpm`
- AppImage: `dxfsketcher-1.5.2-*.AppImage`
- AppImage update companion: `dxfsketcher-1.5.2-*.AppImage.zsync`

## Notes

- Linux is the main release target for 1.5.2
- Windows and macOS builds are still planned for later
- `DXF` remains the main editable workflow
- `SVG` export is available through `Save As`
